Я не програміст: пояснюй просто, маленькими кроками. Не роби `push`, GitHub Actions або
надсилання в Telegram без окремого прямого дозволу. Жива система завжди проходить шлях:
тести → локальний commit → push → ручний Actions → Telegram → перевірка логів.

## Головна ідея продукту

SignalPilot — не генератор одночасних LONG і SHORT. Це помічник для ручного трейдера:

1. 4h визначає режим ринку.
2. У висхідному режимі бот шукає лише LONG; у низхідному — лише SHORT.
3. У діапазоні дія допускається лише біля меж; у нечіткій картині — `NO TRADE`.
4. Протилежний напрямок — це тільки попередження про можливий злам тренду, а не вхід.

перевірити `git status --short`; якщо файл усе ще не додається, зробити його копію через
